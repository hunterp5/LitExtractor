# PatentExtractor

PatentExtractor is a desktop application for finding chemical structures and related information in patent and research PDFs. Its PySide6 interface presents extracted molecules and reactions for review; OpenChemIE handles model-backed document extraction, and RDKit parses, validates, enriches, ranks, and depicts structures.

## Features

- Extract structures from document figures and chemical entities from text.
- Process figure–label coreferences by default to associate structure figures with labels; reactions are optional.
- Review structures, SMILES, identifiers, source pages, formulas, molecular weights, and InChIKeys.
- Merge duplicate molecules by InChIKey.
- Export molecule data to CSV, SDF, or SMILES.
- Choose CPU or CUDA for model inference and customize the application theme and structure display.
- A simple centered workspace message shows when to open a PDF and reports initial extraction progress.

OpenChemIE models are large and can be slow on CPU. Model weights may be downloaded the first time extraction runs. The GUI can still start when optional extraction dependencies are unavailable; it reports missing runtime components when extraction is requested.

## Requirements

- Python 3.10 or 3.11 (the versions currently documented and tested for this project).
- A compatible PyTorch 2.x and torchvision installation. CUDA is optional.
- Poppler tools (`pdfinfo` and `pdftoppm`) available on `PATH` for PDF page rendering through `pdf2image`.
- Network access on the first model-backed run unless the required model weights are already cached.

## Installation

### 1. Create and activate a virtual environment

From the project directory, on Windows PowerShell:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
```

On macOS or Linux, use `python3 -m venv .venv` and `source .venv/bin/activate` instead.

### 2. Install PyTorch

Install a PyTorch 2.x and torchvision build that matches your operating system and hardware. For a CPU-only installation:

```powershell
python -m pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

For CUDA, use the command generated by the [official PyTorch installation selector](https://pytorch.org/get-started/locally/). Install PyTorch before the remaining packages so the selected build is retained.

### 3. Install the application and extraction stack

```powershell
python -m pip install --no-deps -r requirements.txt
python -m pip install -e ".[dev]"
```

These two stages are intentional: the pinned OpenChemIE revision declares `torch<2.0` in its upstream metadata, which conflicts with the PyTorch 2.x build used by this project. The first command installs the curated runtime and model package pins without resolving that incompatible metadata; the second installs PatentExtractor in editable mode with its development tools. This is the shortest safe workflow with the current upstream pins. Avoid installing OpenChemIE separately or replacing the first command with a plain `pip install -r requirements.txt`; a one-step resolver-based install is not reliable until the upstream metadata conflict is resolved.

### 4. Install Poppler

Install Poppler using your platform's package manager or a trusted platform build, then make sure `pdfinfo` and `pdftoppm` are on `PATH`. See the [`pdf2image` installation guide](https://pdf2image.readthedocs.io/en/latest/installation.html) for platform-specific instructions.

## Run

From the project directory:

```powershell
python -m patentextractor
```

After an editable installation, the `patentextractor` console command is also available.

## Use the application

1. Open a PDF using **File → Open PDF** or the Open PDF control.
2. Select the sources to process: figures, text, coreferences, or reactions.
3. Optionally set a page range, a molecule limit, a device, and the crop expansion.
4. Start extraction and review the results in the Molecules and Reactions tabs. Each extraction is kept in its own result tab; right-click a result tab and confirm to delete it.
5. Export molecule results through **File → Export**. Exports use the currently active result tab.

Molecule crop expansion is **0% by default**: the detected molecule box is not enlarged before cropping. Users can choose a larger margin in the Extract panel. A separate fixed 8% context margin is applied earlier to parent figure regions for layout detection; it is not controlled by the molecule crop setting. Both crop stages use source-image pixels and clip at image boundaries.

The interface includes Light, Dark, Groovy, and custom color themes. Structure size and fonts can be adjusted in Settings.

## Tests

Run the model-free default suite with:

```powershell
python -m pytest -q
```

The suite does not download model weights. Model-backed tests are marked as integration tests and can be run explicitly with:

```powershell
python -m pytest --run-integration -m integration
```

The end-to-end integration test and other tests needing real patent content use the local one-page sample `samples/ddr2_sub.pdf`. The sample is not distributed with the repository; tests that need it skip when it is unavailable. Other small PDFs are generated in tests that specifically exercise PDF parsing, the compatibility shim, or page slicing. Integration tests also require Poppler, cached or downloadable model weights, and the relevant extraction runtime.

Check Python style with:

```powershell
python -m ruff check patentextractor tests
```
